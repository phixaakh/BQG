Prototype security boundary

The default admin account is created on first launch. This browser-only demo hashes passwords but does not provide server-side authentication, encrypted shared storage, multi-device sync, or protection from a person with full access to the device/browser profile. Change the default password immediately and do not use real confidential project data until server-side security is implemented.
